# Rossini Arrows

Look at the three cells at each end of every row and column. A marked edge triple is an arrow: its digits must increase from the edge toward the centre. An unmarked edge triple must not be strictly increasing or strictly decreasing in that direction.

## SudokuBank use

Use **Cell groups** to mark each arrow. Each group must contain exactly three cells at one end of a row or column, in order from the edge toward the centre. No input values are used. Unmarked edge triples are checked automatically as part of the whole-grid rule.

## Limitations and interactions

Only the first or last three cells of each row and column are considered. Marked arrows must increase from the edge inward; decreasing marked arrows are not supported. Unmarked triples may contain equal adjacent digits, but may not be strictly monotonic in either direction. Groups shorter than three cells are ignored by the script; groups longer than three cells or groups that do not match a valid edge triple cause an error.

## Implementation notes

The JavaScript implementation is in `constraint.js`. It uses the built-in `LessThan` relationship for the two steps of each marked arrow. It uses `constraint.require` for unmarked edge triples, rejecting both strictly increasing and strictly decreasing sequences. Edge triples are keyed by their cells without regard to order, while the group's cell order determines the marked arrow's direction.
