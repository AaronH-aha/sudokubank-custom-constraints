# Magic Square ✨

For each marked 3×3 square, all nine digits must be different, and the three rows, three columns, and two diagonals must all have the same sum.

## SudokuBank use

Use **Cell groups**. Add one group containing only the centre cell of each magic square. The centre must have all eight surrounding cells on the grid. No input values are used.

## Limitations and interactions

The rule applies only to the eight row, column, and diagonal sums and distinctness within each marked 3×3 square. It does not constrain other directions or require a particular magic sum. SudokuBank's other rules continue to apply to these cells.

## Implementation notes

The JavaScript implementation is in `magic-square.js`. It uses the built-in `AllDifferent` relationship for the nine cells and separate `SameSum` relationships for the rows and columns, so no cell is repeated within either call. Since both sets cover all nine cells, their common totals are necessarily equal. The two diagonals and middle row all share the centre. Removing it leaves three disjoint pairs; one `SameSum` relationship compares those pair totals, which makes the original three line totals equal when the centre is added back. The script checks that the centre has eight king-move neighbours, then uses cell offsets to build the lines in their correct order.
