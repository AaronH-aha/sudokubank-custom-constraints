# Community Sudoku Constraints

A community-maintained collection of custom constraints for Sudoku puzzles.

The aim is to make constraints easier to share, understand, and reuse. Contributions are welcome, whether you are adding a new constraint, improving an existing one, or clarifying its documentation.

## Using a constraint

Each constraint lives in its own folder under `constraints/`. Read its accompanying documentation for what it does, how to use it, and any examples or limitations.

## Contributing

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request. In short: include the constraint code, explain the rule in plain language, and provide an example when practical.

## Where constraints appear

This repository is a community collection of constraints for SudokuBank. Inclusion here does not guarantee inclusion in SudokuBank; the maintainer makes the final decision.

## Repository setup

Maintainers can use [GITHUB_SETUP.md](GITHUB_SETUP.md) for the initial GitHub settings. The [constraint template](constraints/_template/) is the starting point for new contributions.
